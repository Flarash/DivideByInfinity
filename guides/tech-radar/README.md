# Tech radar

Practices for staying current without burning out: the personal tech radar
discipline and the information-diet design that feeds it.

## Guides

- [**Building a personal tech radar**](./building-a-personal-tech-radar.md) —
  the four rings (Adopt / Trial / Assess / Hold), quadrants by category, the
  quarterly review ritual, input sources, the "second blog post" rule, and the
  anti-patterns to avoid (radar as wishlist, radar as marketing, no Hold ring).
- [**Keeping current without burning out**](./keeping-current-without-burning-out.md)
  — the diet hierarchy, the "one signal per week" audit, batching consumption,
  the "wait for the second post" filter, distinguishing hype from durable
  shifts, the minimum-viable input stack, newsletter triage, and the bookmark
  graveyard problem.
