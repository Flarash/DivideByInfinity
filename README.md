# DivideByInfinity

Personal tutorials and guides on **AI tooling, integrations, and other tech I work with**
— from AI coding assistants, agentic CLIs, MCP servers, and IDE integrations, to the
occasional deep-dive on adjacent topics like device modding and developer workflows.

Everything here is written in plain Markdown so it renders natively on GitHub. No site to
build, no toolchain to install — just open the files.

## Sections

- 📘 [**Tutorials**](./tutorials/) — step-by-step, hands-on walkthroughs. Start here if you
  want to follow along and build something concrete.
- 📗 [**Guides**](./guides/) — reference-style explainers, cheat sheets, and
  conceptual deep-dives. Use these to look things up.
- 🧰 [**Tools**](./tools/) — content organized per tool or integration (e.g. Copilot CLI,
  Claude Code, MCP servers, etc.). Use these as an index when you know which tool you care
  about.

## How to use this repo

Browse from the top-level folders, or use GitHub's file finder (press `t`) to jump to a
specific guide. Each section's `README.md` lists what's currently inside.
